[ RULES ]
Non-negotiable
One buttonThe square sweep. .btn outline is default, .solid inverts for one primary action per view, .sm is chrome scale. No other button exists.
Button border1.5px via --btn-bw. Line-height is calc(3em - (var(--btn-bw) * 2)) — never hard-code it.
Focus ring1px accent, declared once, globally. Never per component; a missed control falls through to browser-default blue.
IconsLucide only, stroke 1.75. 20px standalone, 18px for a control inside a section rule.
Radius0px everywhere. No exceptions.
GradientsNever. Any kind, anywhere.
ToggleAlways the final element on the right of any bar. Actions go immediately before it.
Self-containedInline CSS and JS. No external fetch, no build step, opens from file://.

One .dl per line: .a added, .r removed, .h hunk header, bare for context. The leading marker sits in <i> so it can be coloured and given its own 2ch column. Optional: a .diff-head filename bar, and <mark> around an intra-line change when a one-token edit would otherwise be missed.

Four signalsBar, tint, coloured marker, literal +/-. Green/red is the pair that fails for colourblind readers, so the block must still read with hue stripped out.
Blocks, not <pre>Inline spans tint only as far as the text runs; display:block inside <pre> doubles the leading. Block children of a plain div avoid both, and width:max-content;min-width:100% keeps the tint full width through a horizontal scroll.
CopyNo <pre> and no newlines in the markup, so the handler joins .dl text with \n. Still textContent, never innerHTML.
Not includedLine numbers, side-by-side split, syntax highlighting. Each needs a gutter that fights the bar or a tokenizer, and neither earns it in a read-once document.

AffordancePurpose
Section commentSpeech-bubble in any section rule. For "this whole section is wrong".
Quoted commentSelect text, click the chip. The exact phrase is quoted into that section.
Decisions + catch-allStructured choices, then a free-text box. Most useful feedback lands in the box.
Export format

Plain text only, so it survives a chat box. Unanswered items emit (not answered) rather than being dropped — the difference between "no" and "skipped" matters. Quotes appear under their section with a > marker.

Example decision
Radios for one-of-N, checkboxes for many-of-N. Square, never circles. Whole label clickable.
